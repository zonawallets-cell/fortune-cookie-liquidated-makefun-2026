One fortune cookie line, 102 characters, 17 words, for a crypto trader who has just been liquidated. It opens in the classic oracular fortune voice — a windfall is coming — names the loss plainly, and the punchline breaks the formality: the windfall is exactly enough to buy this cookie.

The entry:

> `A windfall is coming, trader: your liquidated position has freed up exactly enough to buy this cookie.`

102 characters, 17 words, one line, valid UTF-8 — inside the 160-character gate and the 20-word limit in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–160 characters, at most 20 words, single line, non-whitespace, valid UTF-8) before and after writing.
